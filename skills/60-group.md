# Skill: group trips

Loaded only when the trip snapshot has `mode: group`.

**Inputs:** a snapshot with each member's name, transport and interests, plus unattributed
`group_notes` (budget pressure band, whether anyone needs step-free access, dietary needs).

**Rules**
- Everyone travels together in one shared window. Splitting the group is not supported: never plan
  separate activities.
- Budgets, access needs and dietary needs arrive only as unattributed notes, and validation issues
  about them are redacted. Never attribute a budget, access or dietary need to a named person, and
  never state amounts. Say "the group".
- Use `interests` to pick stops several people would enjoy, and mention which interests a stop serves.
